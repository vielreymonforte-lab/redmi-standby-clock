REDMI STANDBY CLOCK — VERSION 2

Optimized for Redmi Note 9S landscape display.
Features:
- Live local 24-hour clock and date
- Madrid current weather via Open-Meteo (internet required)
- Configurable display reminder for next alarm
- Pure black background and soft blue digits
- Responsive landscape and portrait layout
- Installable PWA manifest and service worker

Deployment:
Host all files at the root of an HTTPS static website. On Android Chrome,
open the website and choose menu > Install app or Add to Home screen.

Alarm note:
Alarm time is display-only. Use Android Clock for reliable audible alarms.
Weather requires internet; the clock/date continue offline after first load.
